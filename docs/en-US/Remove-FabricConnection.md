# Remove-FabricConnection

## SYNOPSIS

Removes a Fabric connection.

## SYNTAX

```
Remove-FabricConnection -ConnectionId <guid> [-WhatIf] [-Confirm]
```

## EXAMPLES

### EXAMPLE 1

```powershell
Remove-FabricConnection -ConnectionId '11111111-1111-1111-1111-111111111111'
```

## PARAMETERS

- **ConnectionId**: ID of the connection to remove.
