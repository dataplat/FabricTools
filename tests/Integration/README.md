# Integration Tests

This folder contains end-to-end integration tests that call the live Fabric REST API.
No mocking is used — a valid authenticated session is required before running.

## Prerequisites

```powershell
Connect-FabricAccount
```

## Running the tests

```powershell
Invoke-Pester -Path "tests/Integration/" -Tag "Integration" -Output Detailed
```
